## ⚠️ Common Mistakes to Avoid

### ❌ Don't:
- Overuse exact-match keywords as anchor text ("istighfar counter" every time)
- Link to too many pages per section (3-4 max)
- Create self-referential links (page linking to itself)
- Use generic anchor text only ("click here", "link")
- Place all links in footer (looks spammy)
- Ignore mobile usability (ensure links work on phones)
- Forget about relevance (only link when contextually appropriate)

### ✅ Do:
- Vary anchor text naturally
- Link when it adds value to reader
- Test all links before publishing
- Use consistent styling (emerald-600 + hover:underline)
- Place links where users expect them (body text, not footer)
- Monitor performance with analytics
- Update anchor text if CTR is low
