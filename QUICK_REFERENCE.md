# TasbihHub Internal Linking - Quick Reference Cards

## 🎯 At-a-Glance Strategy

### The 3 Pillar Principles

1. **Topical Authority**: Content naturally connects Islamic education (blog) → Tool usage (counter) → Related practices (cross-linking)

2. **User Intent Matching**: Users seeking information → Blog articles. Users ready to practice → Counter tools. This structure guides them naturally.

3. **Natural Link Equity**: Home page (highest authority) → Tasbih Counter (pillar) → Related tools (support) → Blog (authority building)

## ✅ Anchor Text Checklist

**Good Examples (USE THESE):**
- ✅ "tasbih counter"
- ✅ "istighfar counter"
- ✅ "Durood Counter"
- ✅ "zikr counter"
- ✅ "explore our dhikr counter"
- ✅ "Learn more about istighfar"
- ✅ "Discover the benefits of durood"
- ✅ "Read our blog articles"
- ✅ "explore the Islamic benefits of zikr"

**Bad Examples (AVOID):**
- ❌ "click here"
- ❌ "read more"
- ❌ "link"
- ❌ "free online istighfar counter for Muslims" (over-optimized)
- ❌ "istighfar counter, dhikr counter, tasbih counter" (keyword stuffing)
- ❌ "tasbih counter" (repeated too many times in same section)

## 🎨 HTML/CSS Classes to Use

**All internal links should have this styling:**

```tsx
className="text-emerald-600 hover:underline"
```

**In special "highlight" boxes:**

```tsx
className="text-emerald-600 hover:underline font-semibold"
```

**No links should:**
- Use `font-bold` (too heavy)
- Use `underline` without `hover:underline` (always underlined looks cluttered)
- Use different colors (break brand consistency)

## 📱 Mobile Considerations

- All links should work on mobile (test on iPhone + Android)
- Ensure tap targets are at least 48x48px
- Don't place too many links close together (causes accidental taps)
- Use clear anchor text that's readable on small screens
- Avoid light text on light backgrounds or dark on dark

## 🚀 Future Expansion

**When adding new content:**

1. **New Blog Article?**
   - Link to 1–2 relevant tools in body text
   - Add to blog index with context
   - Link FROM tool page back to blog article

2. **New Tool Page?**
   - Add to Related Tools sections on existing tools
   - Create intro blog article if needed
   - Link FROM Tasbih Counter (pillar page)

3. **New Language Version?**
   - Use `hreflang` tags (NOT internal links)
   - Mirror linking structure in new language
   - Keep URLs separate by language path (/id/, /en/, etc.)

## ❓ Common Questions

**Q: How many internal links should each page have?**
A: Aim for 2–4 outbound links per page. Tasbih Counter (pillar) can have up to 5.

**Q: Should I link to every related page?**
A: No. Be selective. Only link when it adds value to the reader.

**Q: Can I use the same anchor text for every link?**
A: No. Vary anchor text to appear natural and avoid over-optimization.

**Q: Should pages link to themselves?**
A: No. Never create self-referential links.

**Q: What if a link increases bounce rate?**
A: Consider moving the link or changing anchor text. Some links should appear later in content, not in intro.

**Q: How do I measure if internal links are working?**
A: Check Google Search Console for internal link impressions. Track average position before/after implementation.

## 📞 Questions or Issues?

If during implementation you encounter:

- **Broken links**: Double-check the URL path is correct
- **Styling issues**: Ensure `className` includes both `text-emerald-600` and `hover:underline`
- **Anchor text unclear**: Refer to "Good Examples" section above
- **Links not appearing**: Verify `<Link />` component is imported from `next/link`
